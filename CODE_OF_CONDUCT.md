# Code of Conduct

Huge Company welcomes respectful participation in project discussions. Everyone taking part in issues, pull requests, reviews, and other project spaces is expected to help keep them constructive and safe.

## Our standards

Examples of behavior that supports this community include:

- Being respectful and considerate of different viewpoints and experiences.
- Giving clear, useful feedback focused on the work.
- Accepting responsibility for mistakes and correcting them constructively.
- Respecting project ownership, privacy, and the permissions described in [LICENCE](LICENCE).

Unacceptable behavior includes harassment, personal attacks, discriminatory language, threats, deliberate disruption, sharing private information without consent, or repeatedly ignoring project boundaries.

## Reporting and enforcement

Report conduct concerns privately to [namastehuge@gmail.com](mailto:namastehuge@gmail.com) with a description and any relevant links. Please do not post private or sensitive details in a public issue. Project maintainers will review reports and may edit or remove content, restrict participation, or close access to project spaces as appropriate.

## Scope

This code applies in project repositories, issues, pull requests, reviews, and other spaces where someone is representing or participating in the Huge Company project community.
