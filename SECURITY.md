# Security Policy

## Supported versions

Security fixes are currently considered for the active V4 website branch. Older snapshots may not receive security updates.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [namastehuge@gmail.com](mailto:namastehuge@gmail.com) with the affected page or component, steps to reproduce, and any relevant impact. Do not open a public issue for an unpatched vulnerability or include credentials and personal data in a report.

The Huge Company team will review the report and follow up with next steps. Please allow time for investigation before sharing details publicly.
